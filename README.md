# Умный кредитный кабинет — frontend

Адаптивный прототип для «Альфа-Будущее Хакатона». Страница объясняет ценность кабинета и позволяет пройти путь от выбора компании и задачи финансирования до предварительного подбора продукта и черновика заявки.

Используются только вымышленные профили. Страница не отправляет заявку в банк, не делает скоринг, не рассчитывает процентную ставку и не обещает одобрение. Состояние хранится только в памяти вкладки и исчезает при её обновлении.

## Сценарий проверки

1. Нажмите «Начать подбор» и выберите один из четырёх готовых профилей компаний. Это основной путь без внешних сообщений.
2. Выберите задачу финансирования из шести вариантов или опишите свою, укажите сумму и срок.
3. После короткого этапа сопоставления посмотрите предварительный подбор из двух типов продукта. Можно выбрать второй вариант вручную.
4. Проверьте ФИО и роль контактного лица, подставленные из профиля; при необходимости измените их.
5. Соберите черновик заявки и проверьте его сводку.

Дополнительный путь входа по номеру использует вымышленный номер `+7 900 000-00-00` и **тестовый код 1221**. Код умышленно не показывается в интерфейсе и поле ввода маскируется. СМС не отправляется; номер и ФИО не передаются на сервер. Это проверка интерфейсного сценария, а не механизм защиты учётной записи.

[Схема Miro](https://miro.com/app/board/uXjVEXdaI_M=/) показывает вход и выбор профиля перед подбором. В хакатонном кейсе SMS не должен быть частью основного пути, поэтому вход по коду остаётся необязательным.

В первом релизе ограничены именно **кредитные продукты**: оборотные средства и инвестиционный кредит. Задач финансирования больше, но текущая логика лишь сопоставляет цель с типом продукта и не оценивает кредитоспособность. Промежуточные экраны показывают локальную проверку введённых полей и подготовку сводки; сетевых запросов нет.

## Продуктовые решения

На публичных страницах [Альфа-Банка](https://alfabank.ru/sme/profits/businesscredit/) вход начинается с телефона и SMS, после чего запрашиваются сведения о бизнесе; [Точка](https://tochka.com/knowledge/kredity/usloviya-kreditovaniya-yuridiceskix-lic/) запрашивает ФИО, ИНН и телефон для заявки, а [Т-Банк](https://www.tbank.ru/business/help/loans/turnover/get-turnover/get-new/) отделяет предварительный результат от дальнейшей проверки. Для хакатонного прототипа ФИО контактного лица появляется перед черновиком и заполняется из вымышленного профиля, чтобы не создавать лишний шаг до подбора. Промежуточный экран называет только те действия, которые выполняет локальная логика, без имитации банковского скоринга.

## Запуск

```sh
npm ci
npm run dev
```

Сборка: `npm run build`.

## Интерфейс

Используются React, Vite и компоненты [Alfa Core DS](https://core-ds.github.io/core-components/master/?path=/docs/intro--docs) с темой `site`. Кнопки и поля формы импортируются из официального пакета, а визуальная композиция и анимации лендинга написаны в CSS. При `prefers-reduced-motion` анимации отключаются.

Иллюстрация героя предоставлена заказчиком. Pinterest-ссылка использована как референс света и движения; сторонний ролик в проект не скопирован.

CI этого репозитория собирает frontend независимо от backend и scoring.
