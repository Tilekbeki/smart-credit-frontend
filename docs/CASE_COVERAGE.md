# Покрытие кейса «Умный кредитный кабинет предпринимателя»

Сверка с официальным PDF «Альфа_Хак_Умный_кредитный_кабинет», с. 2–15, по состоянию на 26 октября 2026 года. Описан совместимый комплект React, Go, Python scoring и PostgreSQL, закреплённый в общем репозитории `smart-credit`.

## Что покрыто сейчас

| Требование | Реализовано | Граница прототипа |
| --- | --- | --- |
| Веб-путь предпринимателя | Гостевой чат с предварительным подбором, вход с учебным профилем, обычная форма либо чат, несколько черновиков, документы, отправка, статус и история одной заявки | Произвольная регистрация нового предпринимателя отсутствует |
| Оценка и решение | Worker Go выполняет синтетические предварительные проверки, вызывает `logreg_v1`, сохраняет оценку и отдельно применяет политику `go-demo-v2` | Рекомендация скоринга не является кредитным решением; технический сбой не превращается в отказ |
| Исходы и действия | `approved`, `counter_offer`, `rejected`, `manual_review`; клиент видит условия либо публичное объяснение, принимает или отклоняет предложение | `signed` — учебное подтверждение; реальная подпись и выдача денег отсутствуют |
| Сторона банка | Сотрудник входит под отдельной ролью, видит очередь и assessment, проводит ручное рассмотрение с внутренним комментарием и отдельным объяснением клиенту | Нет реального банковского контура и внешних проверок |
| Воспроизводимость | Общий Docker Compose, закреплённые submodule-коммиты, тестовые профили и smoke через frontend `/api/` | Для приватных репозиториев требуется доступ жюри; финальный hash указывается после заморозки версии |

## Клиент без счёта в Альфа-Банке

Учебные компании имеют разные источники финансовых данных. Для клиента без подтверждённых оборотов заявка доступна без открытия счёта в Альфе, но backend требует выписку при отправке; ошибка `422` сохраняет тот же черновик. После загрузки выписка остаётся связанной с той же заявкой. Для профиля с учебными подтверждёнными оборотами выписка по умолчанию не нужна. Выбор банка счёта в боковом меню frontend — локальная подсказка пользователя; она не подтверждает обороты и не заменяет серверные проверки. См. также [карту путей](ACCOUNT_JOURNEYS.md).

Это **учебные профили**. Регистрация произвольной компании, проверка содержимого выписки, подтверждение оборотов реальным банком, открытие счёта в Альфе и выдача средств не реализованы. Интерфейс не должен объявлять деньги полученными после подбора, загрузки документа, scoring или учебного `signed`.
