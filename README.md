# Умный кредитный кабинет — frontend

Адаптивный интерфейс учебного прототипа для «Альфа-Будущее Хакатона». Предприниматель выбирает цель финансирования, отправляет заявку, получает автоматическое решение, подтверждает условия и видит квитанцию о зачислении на тестовый счёт. Заявка и её статусы сохраняются в отдельном backend; после обновления страницы кабинет восстанавливает последнюю заявку.

Профили компаний, финансовые показатели, условия и деньги вымышленные. Отправка в настоящий банк, юридическое подписание и реальный перевод не выполняются.

## Полный сценарий

1. Нажмите «Начать подбор» и выберите один из четырёх профилей. Основной путь не требует телефона.
2. Выберите задачу, сумму и срок. Для свободной задачи выберите продукт вручную.
3. Проверьте ФИО и роль контактного лица, которые подставлены из профиля, затем соберите черновик.
4. Нажмите «Отправить заявку». Backend сохранит её в SQLite, а scoring вернёт `approved`, `counter_offer` или `rejected` с причинами.
5. Для одобренной суммы подтвердите учебные условия и нажмите «Подтвердить и получить средства». Появятся статус `funded` и квитанция о тестовом зачислении.
6. Обновите страницу: сохранённый результат загрузится с backend по ID заявки.

Дополнительный путь по номеру использует вымышленный номер `+7 900 000-00-00` и **тестовый код 1221**. Код не показывается в интерфейсе, поле ввода маскируется. СМС не отправляется, номер остаётся в браузере. Это проверка сценария входа, а не механизм защиты. [Схема Miro](https://miro.com/app/board/uXjVEXdaI_M=/) иллюстрирует вход и выбор профиля.

## Запуск

Для всей системы используйте общий репозиторий [`smart-credit`](https://github.com/Tilekbeki/smart-credit): `git clone --recurse-submodules`, затем `docker compose up --build`. Интерфейс доступен на `http://127.0.0.1:8080`.

Для локальной разработки запустите scoring на `127.0.0.1:8001`, backend на `127.0.0.1:8000`, затем в этом репозитории:

```sh
npm ci
npm run dev
```

Vite проксирует `/api` на backend. Сборка: `npm run build`.

## Интерфейс и границы

Используются React, Vite и компоненты [Alfa Core DS](https://core-ds.github.io/core-components/master/?path=/docs/intro--docs) с темой `site`. Подбор продукта зависит от цели; кредитное решение приходит только от scoring через backend. Условия рассчитываются учебной моделью и не являются ставкой или предложением Альфа-Банка. При `prefers-reduced-motion` анимации отключаются.

Иллюстрация главного экрана предоставлена заказчиком. Pinterest-ссылка использована как референс света и движения; сторонний ролик в проект не скопирован. CI frontend запускается независимо от backend и scoring.
