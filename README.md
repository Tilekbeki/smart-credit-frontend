# Умный кредитный кабинет — frontend

Адаптивный демонстрационный лендинг для «Альфа-Будущее Хакатона». Страница объясняет ценность кабинета от проблемы предпринимателя до действия, показывает два кредитных сценария, локальный демо-вход, выбор синтетической компании и интерактивный подбор типа продукта по цели финансирования.

Это концепт на синтетических данных. Страница не отправляет заявку, не рассчитывает кредитное решение и не обещает одобрение.

## Демо-вход

Нажмите «Открыть демо» и выберите синтетический профиль компании. Дополнительно можно попробовать вход по номеру: подставленный `+7 900 000-00-00` вымышленный, но можно ввести другой российский номер. Кнопка «Получить демо-код» показывает код прямо на странице. Введите **1221**, затем выберите один из двух профилей.

СМС не отправляется: номер не передаётся на сервер и не сохраняется в браузерном хранилище. Вход существует только в состоянии текущей страницы; после обновления страницы его нужно повторить. Кнопка «Выйти» сбрасывает демо-вход.

[Схема Miro](https://miro.com/app/board/uXjVEXdaI_M=/) показывает вход/выбор демо-профиля перед подбором кредита. В хакатонном кейсе основной сценарий должен обходиться без внешних SMS, поэтому для него доступен переход к синтетическому профилю без кода. Код 1221 — дополнительная локальная имитация входа для демонстрации интерфейса.

## Запуск

```sh
npm ci
npm run dev
```

Сборка: `npm run build`.

## Интерфейс

Используются React, Vite и компоненты [Alfa Core DS](https://core-ds.github.io/core-components/master/?path=/docs/intro--docs) с темой `site`. Кнопки и поля формы импортируются из официального пакета, а визуальная композиция и анимации лендинга написаны в CSS. При `prefers-reduced-motion` анимации отключаются.

Иллюстрация героя предоставлена заказчиком. Pinterest-ссылка использована как референс света и движения; сторонний ролик в проект не скопирован.

CI этого репозитория собирает frontend независимо от backend и scoring.
