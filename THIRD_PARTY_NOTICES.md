# Сторонние компоненты и интеграции

Основные прямые зависимости frontend зафиксированы в `package.json` и
`package-lock.json`:

| Компонент | Версия | Лицензия | Использование |
| --- | --- | --- | --- |
| React и React DOM | 19.3.1 | MIT | Веб-интерфейс и состояние экранов |
| Alfa Core Components | 50.37.0 | MIT | Поля ввода, кнопки и дизайн-токены |
| Vite | 8.3.5 | MIT | Сборка и локальный dev proxy |

Транзитивные пакеты и их точные версии перечислены в `package-lock.json`.

Иллюстрация `assets/alpha-cat-hero.png` предоставлена заказчиком для
прототипа. Ссылка Pinterest использована как визуальный референс; сторонние
видео, шрифты и изображения с этой страницы в код не включены.

Профили, компании, финансовые показатели, документы и проверки в сценарии
синтетические. Go backend выдаёт тестовый OTP без отправки SMS; реальные
банковские и государственные API, БКИ, платёжные операции и выдача кредита не
подключены. Frontend обращается только к локальному Go API через `/api`.
